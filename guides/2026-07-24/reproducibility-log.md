## Run header

Record the date, environment, account tier, region, visible version, input licenses, and every non-default setting. Use synthetic or public inputs only.

## Test cases

1. a synthetic document set: save the exact input, settings, raw output, elapsed time, and manual corrections.
2. a restricted tool set in a disposable environment: save the exact input, settings, raw output, elapsed time, and manual corrections.

## Measurements

- permission exceptions
- recovery time
- unbounded action count
- operator review time

Repeat each case once without changing inputs. Keep both results, including failures, instead of reporting only the best run. A reproducible result has enough evidence for a second reviewer to repeat the test and explain meaningful variance.

## Stop rule

Stop if a rerun changes the conclusion without a documented input, version, or configuration change. Do not upload credentials, identity documents, customer records, or private media.
